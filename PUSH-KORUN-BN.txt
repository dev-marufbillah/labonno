==========================================================
 লাবণ্য — GitHub-এ পুরো প্রজেক্ট একবারে পাঠানোর ফাইল
==========================================================

এই zip-এ **পুরো প্রজেক্ট + রেডি git রেপো** আছে (৫টা কমিট, ব্রাঞ্চ `main`)।
মানে আপনাকে git init / commit কিছুই করতে হবে না — শুধু push।

----------------------------------------------------------
ধাপ ১ — GitHub-এ খালি রিপো বানান (একবারই)
----------------------------------------------------------
1. github.com এ লগইন → উপরে ডানে [+] → New repository
2. নাম দিন:  labonno        (Private রাখাই ভালো)
3. ⚠️ "Add a README file" / ".gitignore" — কোনোটাই টিক দেবেন না
4. Create repository → লিংকটা কপি করুন
   (যেমন: https://github.com/maruf/labonno.git)

----------------------------------------------------------
ধাপ ২ — ফোল্ডার বের করুন
----------------------------------------------------------
zip-এ ডান-ক্লিক → Extract All → `LABONNO-PUSH-READY` ফোল্ডার।
(VS Code-এ খোলার দরকার নেই, তবে চাইলে Open Folder করতেই পারেন।)

----------------------------------------------------------
ধাপ ৩ — push.bat ডাবল-ক্লিক
----------------------------------------------------------
• জিজ্ঞেস করবে:  Link:   → কপি করা লিংক পেস্ট → Enter
• নিজে নিজেই push করবে এবং শেষে দেখাবে:
      [OK] Hoye gechhe! Code GitHub e ache
• পাসওয়ার্ড চাইলে → GitHub Personal Access Token দিন
  GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  → Generate new token (classic) → scope: repo → Generate → কপি → পেস্ট

Mac/Linux হলে:  টার্মিনালে ওই ফোল্ডারে গিয়ে  bash push.sh

----------------------------------------------------------
এতে কী কী যাবে না (নিরাপত্তা)
----------------------------------------------------------
node_modules · .next · .mongo-data · *.log
.env.local  ← MongoDB/Cloudinary/Resend কী, কখনো যাবে না
(আমি যাচাই করেছি: হিস্টরিতেও কোনো `.env` ফাইল নেই, শুধু `.env.example`)

----------------------------------------------------------
এরপর কোড বদলালে
----------------------------------------------------------
ঐ একই ফোল্ডারে আবার push.bat ডাবল-ক্লিক — শুধু নতুন পরিবর্তন যাবে।

----------------------------------------------------------
আটকালে
----------------------------------------------------------
• Authentication failed → পাসওয়ার্ড নয়, টোকেন দিন (উপরের ধাপ)
• rejected (fetch first)  → গিট বাশে: git pull --rebase origin main  → আবার push
• link বদলাতে           → git remote set-url origin <নতুন লিংক>
• Git install নেই        → git-scm.com/downloads (তারপর VS Code/টার্মিনাল বন্ধ করে আবার খুলুন)
