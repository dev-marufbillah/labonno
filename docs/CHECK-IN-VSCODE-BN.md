## ভাগ ১ — ফোল্ডার খোলা (২ মিনিট)

**১.** `LABONNO-kit-2026-11-03.zip` ফাইলটা আনজিপ করুন। ভেতরে `labonno` ফোল্ডার পাবেন।

> ⚠️ zip-এর ভেতরেই ডাবল-ক্লিক করে কাজ করবেন না। আগে **Extract** করুন, তারপর ফোল্ডার খুলুন।

**২.** VS Code খুলুন → মেনু থেকে **File › Open Folder…** → সেই `labonno` ফোল্ডার সিলেক্ট করুন।
(বাম দিকে `app`, `components`, `lib`, `public`, `package.json` দেখলে ঠিক জায়গায় আছেন।)

**৩.** টার্মিনাল খুলুন: **Ctrl + `** (Mac-এ **⌃ + `**)।
নিচে টার্মিনাল না এলে **Terminal › New Terminal**।

> **আপনার নিজের ইমেইল (`marufsalauddioffical@gmail.com`) দিয়ে অ্যাডমিনে ঢুকবেন** — এই ঠিকানাটা
> কোডে owner হিসেবে লেখা আছে, তাই `npm run seed:users` চালালেই অ্যাকাউন্টটা super admin হিসেবে তৈরি হবে।
> অন্য কেউ `/register` দিয়ে সাইনআপ করলে সে সাধারণ কাস্টমার হবে; আপনি চাইলে Admin → Users থেকে তাকে admin বানাতে পারবেন।

**৪.** চেক করুন Node আছে কি না:

```bash
node -v
```

`v20.x` বা তার উপরে হলেই ভালো। না থাকলে [nodejs.org](https://nodejs.org) থেকে LTS ইনস্টল করুন (২০ বা ২২), তারপর VS Code বন্ধ করে আবার খুলুন।

## ভাগ ২ — ইনস্টল + সেটআপ (৩–৫ মিনিট)

**৫.** প্যাকেজ ইনস্টল:

```bash
npm install
```

(প্রথমবার ২–৪ মিনিট লাগে। `node_modules` ফোল্ডার তৈরি হবে।)

**৬.** `.env.local` বানান:

```bash
npm run setup
```

এটা `.env.local` ফাইল বানায় আর `BETTER_AUTH_SECRET` নিজেই তৈরি করে দেয়।
এরপর বাম দিকের ফাইল লিস্টে **`.env.local`** ফাইলে ক্লিক করুন — শুধু **একটা লাইন** ঠিক করতে হবে:

```env
MONGODB_URI=mongodb://127.0.0.1:27017
```

- **লোকাল MongoDB** ব্যবহার করলে এটাই রাখুন (পরের ধাপ দেখুন)।
- **MongoDB Atlas** (ক্লাউড, ফ্রি) ব্যবহার করলে এখানে আপনার `mongodb+srv://...` লিংক বসান।
  Atlas নিলে লোকাল mongod লাগবে না — সোজা ধাপ ৯-এ যান।

> 🔒 এই ফাইলটা কাউকে শেয়ার বা গিটহাবে আপলোড করবেন না — এতে পাসওয়ার্ড/কি থাকে।

**৭.** লোকাল MongoDB চালু (Atlas নিলে বাদ দিন):

```bash
npm run db:mongo
```

`mongod` ইনস্টল না থাকলে এই কমান্ড বলবে কোথা থেকে নামাতে হবে। দ্রুত উপায় — MongoDB Community Server ইনস্টল করে আবার চালান।
(আলাদা টার্মিনালে চালু থাকতে দিতে হবে, বন্ধ করবেন না।)

**৮.** ডেমো ডেটা বসান:

```bash
npm run seed
```

শেষে দেখবেন প্রোডাক্ট/ক্যাটাগরি/ব্যানার তৈরি হয়েছে এবং ৩টা অ্যাকাউন্ট তৈরি হয়েছে।

## ভাগ ৫ — অটোমেটেড চেক (এক কমান্ডেই সব)

আলাদা টার্মিনালে (dev server চালু রেখে) বা dev বন্ধ করে:

```bash
npm run typecheck        # কোডে টাইপ ভুল আছে কি না — "০ error" আশা করছি
npm run smoke            # ডেটাবেস + অর্ডার + কুপন + রিভিউ — "40 passed"
npm run check:routes     # লগইন গার্ড — "27 passed"
npm run check:cloudinary # Cloudinary আপলোড+ডিলিট (কি দেওয়া থাকলে)
```

সবগুলো পাস করলে বুঝবেন ভেতরের লজিক ঠিক আছে।

## ভাগ ৬ — সমস্যা হলে

| যা দেখছেন | কারণ | সমাধান |
|-----------|------|--------|
| `MONGODB_URI is not set` | `.env.local` নেই | `npm run setup` চালান |
| `ECONNREFUSED` / `MongoServerSelectionError` | ডেটাবেস চলছে না | `npm run db:mongo` চালু রাখুন, বা Atlas লিংক বসান |
| পোর্ট ৩০০০ ব্যস্ত | আগের সার্ভার চলছে | `npm run dev -- -p 3001` |
| পেজে ডেটা নেই / খালি শপ | সিড হয়নি | `npm run seed` |
| অ্যাডমিনে ঢুকছে না | সিড অ্যাকাউন্ট নেই | `npm run seed` (আবার), পাসওয়ার্ড `Labonno@2026` |
| ছবি আপলোড হচ্ছে না | Cloudinary কি নেই | `.env.local`-এ Cloudinary ৩টা কি বসান (নাহলে লোকাল ফলব্যাক) |
| `npm run db:mongo`: mongod not found | MongoDB ইনস্টল নেই | MongoDB Community ইনস্টল, বা Atlas ব্যবহার করুন |
| `seed:users` এ **"Transaction numbers are only allowed on a replica set member or mongos"** | লোকাল MongoDB সাধারণ (standalone) মোডে চলছে — Better Auth অ্যাকাউন্ট বানাতে transaction ব্যবহার করে | নতুন কোড এটা নিজেই সামলে নেয় (transaction বাদ দিয়ে অ্যাকাউন্ট লেখে)। চাইলে `.env.local`-এ `MONGODB_TRANSACTIONS=false` দিন। তারপর `npm run seed:users` আবার |

## ভাগ ৭ — VS Code-এ কাজ চালিয়ে যেতে

- টার্মিনাল একটাই যথেষ্ট: dev server ওখানে চলুক, চেক কমান্ডের জন্য **+** চেপে আরেকটা টার্মিনাল।
- দরকারি এক্সটেনশন: **Tailwind CSS IntelliSense**, **ESLint**, **Prettier**।
- ফাইল এডিট করে **Ctrl+S** করলেই ব্রাউজার নিজে রিফ্রেশ হবে (Next.js fast refresh)।
- থামাতে হলে টার্মিনালে **Ctrl+C**। ডেটা মুছতে চাইলে `.mongo-data` ফোল্ডার ডিলিট করে আবার `npm run db:mongo` + `npm run seed`।
- প্রোডাকশনে দেওয়ার সময়: `.env.local`-এ আসল ডোমেইন/Atlas/Cloudinary/resend কী বসিয়ে `npm run build` → `npm start`।
