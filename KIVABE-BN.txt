=====================================================================

এই ফোল্ডারে ২টা ফাইল:  push.bat (Windows)  ·  push.sh (Mac/Linux)

---------------------------------------------------------------------
ধাপ ১ — ফাইল দুটো রাখুন
---------------------------------------------------------------------
আপনার প্রজেক্ট ফোল্ডারে (যেখানে package.json আছে) এই ২টা ফাইল কপি করুন।
   ✓ VS Code-এ ফোল্ডার খুলে বাম দিকের লিস্টে package.json দেখা যাচ্ছে —
     ঠিক ওই লেভেলেই push.bat রাখবেন।

---------------------------------------------------------------------
ধাপ ২ — push.bat ডাবল-ক্লিক
---------------------------------------------------------------------
ব্ল্যাক উইন্ডো খুলবে, জিজ্ঞেস করবে:

   Username ba link:  _

শুধু আপনার GitHub username লিখুন (যেমন: maruf) → Enter।
বাকিটা নিজে নিজেই:
   • repo তৈরি (যদি না থাকে)
   • আপনার রিপো:  https://github.com/maruf/labonno.git
   • সব ফাইল commit → push
শেষে দেখবেন:  [OK] Hoye gechhe!

(পুরো লিংক পেস্ট করলেও চলবে — যেমন https://github.com/maruf/labonno.git)

---------------------------------------------------------------------
ধাপ ৩ — পাসওয়ার্ড চাইলে
---------------------------------------------------------------------
GitHub পাসওয়ার্ড নেয় না, টোকেন নেয়:
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
→ Generate new token (classic) → Expiration দিন → scope: ✅ repo
→ Generate → টোকেন কপি → উইন্ডোতে পাসওয়ার্ডের জায়গায় পেস্ট।
(একবারই দেখায় — Notepad-এ লিখে রাখুন। পরে Git মনে রাখবে।)

আটকালে
---------------------------------------------------------------------
• [X] Git install nei            → git-scm.com/downloads → ইনস্টল → VS Code বন্ধ করে আবার খুলুন
• Authentication failed          → পাসওয়ার্ড নয়, টোকেন দিন
• rejected (fetch first)         → git pull --rebase origin main  → আবার push.bat
• repo not found                 → GitHub-এ repo-র নাম ঠিক "labonno" আছে কি না দেখুন,
                                   অথবা push.bat-এ পুরো লিংক পেস্ট করুন
• ডাবল-ক্লিকে কিছু হয় না         → PowerShell খুলে: cd "প্রজেক্ট পাথ"  তারপর  .\push.bat
